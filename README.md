# RSO2
ROS 2（Robot Operating System 2） 是一套開源的機器人軟體開發框架（Middleware），提供程式庫、工具與通訊機制，協助開發者建構機器人系統。雖然名稱中有 Operating System（作業系統），但它本身不是作業系統，而是一個運作於 Linux、Windows 或 macOS 之上的機器人軟體平台。
